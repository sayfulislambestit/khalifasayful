01 / NETWORKING

VLAN Fundamentals

A VLAN (Virtual Local Area Network) logically separates devices into different Layer 2 broadcast domains, even when they share physical switching infrastructure.

Why use VLANs?

  • Segmentation: Separate groups such as staff, servers and guest devices.
  • Organization: Group devices by function or department.
  • Policy control: Apply routing and security rules between VLANs through a Layer 3 device.

Access and trunk ports

An access port usually carries one assigned VLAN. A trunk port can carry multiple VLANs, commonly using IEEE 802.1Q tags. Communication between different VLANs generally requires Layer 3 routing.

02 / NETWORK ANALYSIS

Getting Started with Wireshark

Wireshark helps you inspect network packets and understand how protocols communicate.

A simple learning workflow

  1. Select the correct interface for a capture.
  2. Capture a short session on a network you are authorized to inspect.
  3. Try display filters such as dns, tcp and icmp.
  4. Review source, destination, protocol and timing.

DNS packets illustrate name lookups; TCP packets help explain connections and acknowledgements. Packet captures may contain private information, so handle them carefully.

03 / SYSTEM ENGINEERING

Building a Home Lab

A home lab provides a safe environment to practice system and network administration without changing a production network.

Start small

  • Create one or two test virtual machines.
  • Practice IP addressing, DNS, DHCP and connectivity checks.
  • Document configurations and results.
  • Practice backup and restore with non-critical test data.

Expand gradually as you understand resource requirements. Keep systems updated and do not expose lab services publicly without understanding the security implications.
