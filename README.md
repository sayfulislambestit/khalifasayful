# Khalifa Sayful — Cyber Tech Portfolio

A responsive, static personal portfolio built with HTML, CSS and JavaScript. It is suitable for free hosting on GitHub Pages.

## 1. Before publishing

Replace every instance of:

`https://YOUR-GITHUB-USERNAME.github.io/khalifasayful/`

with your real GitHub Pages URL in:
- `index.html` (canonical URL, Open Graph URL/image and JSON-LD URL)
- `robots.txt`
- `sitemap.xml`

The current content intentionally avoids inventing certificates, project results, contact details or job responsibilities. Update the placeholders with accurate information.

## 2. Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository named `khalifasayful`.
3. Upload all files and the `assets` folder from this package to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. The URL will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/khalifasayful/`
8. Replace the placeholder URLs listed above with the actual URL and commit the changes.

## 3. Google indexing

1. Open Google Search Console: https://search.google.com/search-console/
2. Add your published URL-prefix property.
3. Verify ownership using one of the methods Google offers.
4. Submit `sitemap.xml`.
5. Use URL Inspection to request indexing of the homepage.

Indexing and ranking are not guaranteed and can take time. Do not repeatedly submit the same URL.

## 4. Personalize the site

- Update the education line with your exact degree/program and dates.
- Add verified work responsibilities under Experience.
- Replace the sample project cards with completed projects and real screenshots.
- Add certificates only after obtaining them.
- Add a professional photo only if you want one; place it in `assets/` and update the HTML.
- Add a public professional email only if you want it displayed. Avoid publishing private contact details.

## 5. Local preview

Open `index.html` in a browser. No build tools or paid services are required.

## Files

- `index.html` — page content, metadata and structured data
- `style.css` — responsive Cyber Tech design
- `script.js` — navigation and typing animation
- `robots.txt` — crawler access guidance
- `sitemap.xml` — sitemap for search engines
- `assets/` — favicon and social preview artwork


## Gallery and blog additions
- The homepage includes a Photo Gallery and Blog preview.
- `blog.html` contains three starter learning-note articles.
- Gallery images are placeholders, not your personal photographs. Replace `assets/gallery/photo-1.svg`, `photo-2.svg`, and `photo-3.svg` with your own photos and update their paths in `index.html` if filenames change.
- GitHub Pages is static hosting. Blog posts are edited by updating `blog.html`; there is no login-based admin dashboard.

The homepage gallery now uses the 14 photos supplied by the site owner. Images are stored in `assets/gallery/`. Replace any image file with another photo using the same filename to update it without editing the HTML.
